# Bundled fonts

OpenTab draws every music symbol and every text run as paths taken from the fonts below. They are compiled into `opentab-layout` with `include_bytes!` and shipped unmodified, each with its licence. Both are licensed under the SIL Open Font License, Version 1.1.
